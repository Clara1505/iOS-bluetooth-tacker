# Journal des prompts – Aida

Chaque entrée contient la date et l'heure, l'auteur et le prompt envoyé à l'IA
(sans secret ni donnée réelle). Les entrées sont ajoutées après chaque session,
avant le commit correspondant.

Format d'une entrée :

- **Date et heure** : AAAA-MM-JJ HH:MM
- **Auteur** : Aida
- **Prompt** : texte envoyé
